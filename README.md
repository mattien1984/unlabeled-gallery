# The Unlabeled Gallery

An art history game. Every wall label in the museum has gone missing, and you put them back: name the artist, title, date and movement of 255 works by 110 artists, from Giotto (1305) to Grant Wood (1930).

**Play it:** https://mattien1984.github.io/unlabeled-gallery/

- Ten works per tour, six kinds of question, 1,000 points.
- Medium: pick the artist from four painters of a similar style.
- Hard: type the artist's name from memory.

The whole game is in `index.html`; the paintings are in `img/`.
